💡 操作說明：
  • 方向鍵：移動釣餌位置（每次移動 80 像素）
  • 中央按鈕：連擊攻擊（需要 5-10 次才能撈魚）
  • 圓形進度條：顯示當前連擊進度（0-10）

📋 使用步驟

1 開啟大螢幕顯示

在電腦或大螢幕上打開 fish.html

2 掃描 QR Code

用手機掃描螢幕右上角的 QR Code，開啟控制器

3 靠近感測器

將手機靠近超音波距離感測器（< 10cm），控制器會自動啟動

4 移動釣餌

使用方向鍵移動釣餌，追蹤螢幕上游動的魚

5 對準目標

讓魚進入釣餌周圍的半透明圓圈範圍內

6 連擊撈魚

快速連續按中央按鈕 5-10 次，當連擊數達標且魚在範圍內時，成功撈起！

⚙️ 系統需求

  • 硬體：ESP32 + HC-SR04 超音波距離感測器
  • 網路：所有裝置連接到同一 Wi-Fi（192.168.100.x）
  • 服務：
    • Mosquitto MQTT Broker (port 1883)
    • WebSocket Server (port 8080)
    • HTTP Server (port 8081)
  • ESP32：持續發送距離資料到 esp32/device-01/distance

🎯 遊戲技巧

💡 撈魚策略：
  • 先觀察魚的游動路徑，預判魚的移動方向
  • 將釣餌移動到魚的前方等待
  • 當魚進入範圍圈時，立即開始快速連擊
  • 優先選擇高分數的稀有魚（帶光環或閃光的魚）
  • 連擊有 2 秒時效，如果中斷需要重新累積
⚠️ 注意事項：
  • 手機必須保持在感測器 10cm 內才能操作
  • 連擊按鈕有 0.5 秒冷卻時間，避免誤觸
  • 同一時間只能有一位玩家控制釣餌
  • 如果連擊失敗，請重新對準魚再試一次

🔧 故障排除

❌ 按鈕無反應：
  • 檢查手機是否在感測器 10cm 內
  • 確認 WebSocket 狀態為「已連接」（綠色）
  • 檢查 MQTT broker 是否運行
  • 查看瀏覽器開發者工具的 Console 日誌
⚠️ 釣餌不出現：
  • 至少按一次方向鍵或連擊按鈕來啟動釣餌
  • 刷新 fish.html 頁面重新載入
  • 檢查是否訂閱了正確的 MQTT 主題
ℹ️ 連擊無法撈魚：
  • 確保魚進入釣餌周圍的半透明圓圈範圍
  • 確認連擊數達到 5-10 次（查看圓形進度條）
  • 不要中斷連擊超過 2 秒
  • 有些魚移動很快，需要預判位置
